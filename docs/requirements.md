# Requirements — Team-Tasks MVP

## 기능 요건

| ID | 이름 | 설명 | 우선순위 |
|----|------|------|---------|
| F-01 | 일감 생성 | 팀장이 제목·설명·담당자·마감일을 입력해 일감을 생성한다. 생성 즉시 담당자의 목록에 노출된다. | 최상 |
| F-02 | 일감 목록 조회 | 로그인한 사용자는 전체 일감을 볼 수 있다. 기본 정렬은 마감일 오름차순이며, '내 일감' 필터로 본인 담당 항목만 좁힐 수 있다. | 최상 |
| F-03 | 상태 변경 | 담당자는 자신의 일감 상태를 대기·진행 중·완료 사이에서 자유롭게 전환할 수 있다. 완료 항목은 목록에서 시각적으로 구별된다. | 최상 |
| F-04 | 일감 상세 조회 | 모든 사용자가 일감을 클릭해 제목·설명·담당자·마감일·현재 상태를 확인할 수 있다. | 상 |
| F-05 | 담당자 재배정 | 팀장 또는 관리자가 기존 일감의 담당자를 다른 팀원으로 변경할 수 있다. | 상 |

> 상태 변경(F-03)은 본인 일감에만 적용되며, 전체 열람(F-02)은 모든 역할에 읽기 전용으로 허용한다 (결정 사항 1·5 반영).

## 비기능 요건

| 영역 | 요건 | 측정 기준 |
|------|------|----------|
| **성능** | 목록 페이지 최초 로딩 | LCP(Largest Contentful Paint) ≤ 2.5 s (3G 환경, 일감 100건 기준) |
| **성능** | 상태 변경 응답 | 버튼 클릭 후 UI 반영까지 ≤ 500 ms (낙관적 업데이트 포함) |
| **보안** | 인증 | 모든 API 엔드포인트는 세션 토큰 없이 접근 시 401 반환 |
| **보안** | 권한 경계 | 타인 일감의 상태 변경 시도 시 서버에서 403 반환 (클라이언트 검증에만 의존하지 않음) |
| **가용성** | 서비스 업타임 | 월간 가용률 ≥ 99 % (다운타임 ≤ 7.3 h/월) |
| **접근성** | 키보드 내비게이션 | 마우스 없이 Tab·Enter만으로 일감 생성·상태 변경 완료 가능 (WCAG 2.1 AA 준수) |
