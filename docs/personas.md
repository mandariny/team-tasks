# Team-Tasks 페르소나

> **MVP 헌장** — 단일 테이블 · 기능 5개 이하 · 1일 안에 코드로 옮길 수 있는 분량

---

| 항목 | 팀장 (Task Owner) | 팀원 (Assignee) | 관리자 (Admin) |
|------|------------------|----------------|---------------|
| **역할** | 일감을 생성하고 팀원에게 할당하는 책임자 | 할당된 일감을 수행하고 상태를 갱신하는 실무자 | 전체 프로젝트·구성원을 관리하는 운영자 |
| **기술 수준** | 중급 — 협업 툴 사용 경험 있음, 개발 지식 불필요 | 초급~중급 — 기본적인 웹 UI 조작 가능 | 고급 — 시스템 설정 및 권한 관리 익숙 |
| **주요 시나리오 1** | 새 일감을 만들고 담당자·마감일을 지정한다 | 내게 할당된 일감 목록을 확인한다 | 새 팀원을 등록하고 프로젝트에 배정한다 |
| **주요 시나리오 2** | 진행 중인 일감의 상태(대기→진행→완료)를 추적한다 | 일감 상태를 '진행 중' 또는 '완료'로 변경한다 | 특정 일감을 다른 팀원에게 재배정한다 |
| **주요 시나리오 3** | 완료된 일감과 미완료 일감을 필터링해 현황을 파악한다 | 일감 상세 내용(설명·첨부)을 열어 작업 맥락을 확인한다 | 전체 일감 현황을 한눈에 보고 병목을 파악한다 |
